# The Lost Approach
### A Twine game by Denya

---

## HOW TO RUN

Clone the repository:

```bash
git clone https://github.com/Denya-The-Dev/the-lost-approach.git
cd the-lost-approach
```

Whole game SHOULD run in your browser. No additional software of any kind is required, besides GIT.

**Linux**
```fish
xdg-open index.html
```

**Windows**
```powershell
start index.html
```

**macOS**
```bash
open index.html
```

Alternatively, simply double-click `index.html` to launch the game in your default browser.

## GAME BRIEF
*Summary by AI :D*

**Title:** The Lost Approach

**Story Concept:** An ordinary passenger boards a Scandinavian Airbus A320-200 out of Vágar, heading to Bergen for a long-overdue family reunion. Outside, violent North Sea turbulence batters the airframe. Inside, a heavy silence hangs as memories of strained family ties surface. Unbeknownst to the passenger, their family hasn't just gathered to celebrate—they are waiting on a critical answer only they can bring. Every passing mile through the storm brings both physical peril and emotional reckoning closer.

### SOFTWARE USED

- **Game engine:** [Twine](https://twinery.org/), using SugarCube-2 format, with Tweego compiler
- **Visuals:** MSFS2020 + FNX320
